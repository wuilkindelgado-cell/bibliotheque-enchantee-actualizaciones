# Bibliothèque Enchantée — actualizaciones

Aquí se publican los instaladores de **Bibliothèque Enchantée**.

La app revisa este lugar sola y, cuando hay una versión nueva, ofrece instalarla:
verifica la huella SHA-256 del instalador antes de ejecutarlo y conserva todos los datos.

Para instalar a mano: descarga el último `Bibliotheque-Enchantee-Setup-*.exe` desde **Releases**.
